# Мої валюти

Вебзастосунок для особистого обліку валютних заощаджень. Для людей, які тримають долари чи євро на картках українських банків і докуповують валюту частинами.

**Проблема:** застосунок банку показує лише баланс. Він не пам'ятає, за яким курсом купувалась валюта, тому не видно, чи заробив ти на зміні курсу і чи вигідно докуповувати зараз. Курси Monobank, ПриватБанку й НБУ доводиться порівнювати вручну.

**Рішення:** «Мої валюти» збирає валютні картки в одному місці, сам знаходить покупки валюти у виписці Monobank, рахує середній курс покупки, прибуток чи збиток і підказує, чи вигідно купувати зараз.

## Реалізовані функції

- **Мої картки:** валютні рахунки Monobank (USD, EUR) підтягуються автоматично; картка ПриватБанку додається вручну.
- **Синхронізація покупок:** обміни гривні на валюту знаходяться у виписці Monobank за останній місяць.
- **Результат курсу:** середній курс покупки (метод середньої вартості: продаж валюти не змінює середній курс решти), скільки вкладено, скільки варте зараз, прибуток або збиток у гривнях і %.
- **«Вигідно купити зараз?»:** порівняння поточного курсу з вашим середнім.
- **Калькулятор покупки** з QR-кодом на monobank.ua (сама покупка проходить у застосунку банку).
- **Курси:** НБУ, Monobank, ПриватБанк у таблиці; графік НБУ за 7 днів – 1 рік з точками ваших покупок; конвертер USD/EUR/UAH.
- **Історія покупок:** таблиця з фільтрами та експорт у CSV для Excel.
- **Сповіщення про курс:** «повідом, коли EUR нижче 50,50».
- **Режим презентації:** ховає ім'я, номери карток і суми.
- **Погодний фон:** анімація за реальною погодою (дощ, сніг, гроза…).
- **Демо-режим:** без токена Monobank застосунок показує вигадані картки й покупки — можна запустити й показати без особистих даних. Демо- і справжні дані зберігаються окремо й не змішуються.
- **Доступ з телефона:** вдома по Wi-Fi або з будь-якого місця через інтернет (тунель Cloudflare, `start-internet.bat`), за QR-кодом у «Налаштуваннях»; зі справжніми даними — лише з PIN-кодом.
- **Telegram-бот:** курси, баланс і прибуток, порада «чи купувати зараз», сповіщення про курс (працюють, навіть коли сайт закритий), нова адреса сайту після запуску. Бот приватний — відповідає лише власнику, який підключився кодом із «Налаштувань».
- Перевірка введення, темна і світла тема, адаптив для телефона.

## Технології

- Сайт: HTML, CSS, JavaScript без фреймворків; Chart.js 4.4 (графіки), qrcode.js (QR-код), Canvas (погодний фон).
- Сервер: Python 3.11+, FastAPI, Uvicorn, httpx, python-dotenv.
- База даних: SQLite.
- Зовнішні API: НБУ, Monobank (публічний і особистий), ПриватБанк, Open-Meteo.
- Розробка: Kiro IDE та AI-асистент Claude; кожну зміну перевірено вручну в браузері.

## Установлення та запуск

Потрібні Python 3.11 або новіший і браузер. Логін, пароль і особисті дані **не потрібні** — без токена запуститься демо-режим.

**Windows:** розпакуйте ZIP і двічі клацніть **`start.bat`**. Він сам встановить бібліотеки й запустить застосунок.

**Будь-яка система, однією командою** (з папки `moi-valyuty`):
```
pip install -r server/requirements.txt
python server/main.py
```

У терміналі з'являться адреси:
```
  Мої валюти запущено
  На цьому комп'ютері:   http://localhost:8001
  З телефона (та сама Wi-Fi): http://192.168.0.105:8001   — демо-режим
```
Відкрийте **http://localhost:8001**. Термінал не закривайте; зупинити — Ctrl+C.

Потрібен інтернет: курси завантажуються з НБУ, Monobank і ПриватБанку. Без інтернету показуються останні збережені курси.

**Свої картки (необов'язково):** отримайте токен на api.monobank.ua (QR у застосунку monobank), створіть файл `server/.env` за зразком `.env.example` з рядком `MONO_TOKEN=ваш_токен` і перезапустіть сервер. Токен нікому не передавайте.

### Доступ з телефона

**Вдома по Wi-Fi.** Запустіть `start.bat`, відкрийте **Налаштування → 📱 Відкрити на телефоні** і наведіть камеру телефона на QR-код. Телефон має бути в тій самій Wi-Fi. Якщо адреса не відкривається, дозвольте Python у вікні брандмауера Windows (з'являється при першому запуску, «Приватні мережі»).

**З будь-якого місця (мобільний інтернет, інше місто).** Запустіть **`start-internet.bat`** замість `start.bat`:
1. При першому запуску сервер сам завантажить програму `cloudflared` (~38 МБ, у `server/bin`).
2. У вікні з'явиться адреса на кшталт `https://brave-otter-xxxx.trycloudflare.com`, а в «Налаштуваннях» — QR-код на неї.
3. Сервер працює на вашому ПК: комп'ютер і вікно `start-internet.bat` мають бути ввімкнені. Дані нікуди не копіюються — Cloudflare лише передає зашифроване з'єднання.
4. Адреса **нова при кожному запуску** — після перезапуску відскануйте QR ще раз.

**PIN-код.** Демо-режим і демо-акаунт відкриваються з телефона одразу. **Справжні дані** — лише після PIN-коду: додайте в `server/.env` рядок `APP_PIN=ваш_код` і перезапустіть сервер.
- Вдома по Wi-Fi PIN може бути будь-яким, **для інтернету — мінімум 6 символів** (інакше тунель не запуститься).
- Без PIN зі справжніми даними ваш акаунт відкривається тільки на цьому комп'ютері; з інших пристроїв доступний лише демо-акаунт.
- 5 неправильних спроб з однієї адреси — блокування на 5 хвилин; 30 невдалих спроб за годину загалом — вхід з інших пристроїв блокується на годину (на самому ПК все працює; перезапуск сервера знімає блокування).
- Після входу телефон пам'ятає вас 30 днів. Змінили PIN — усі пристрої треба буде увійти заново.

**Демо-акаунт для гостей.** Під QR-кодом свого акаунта в «Налаштуваннях» є другий QR — **🧪 Демо-акаунт на телефоні** (адреса закінчується на `/?demo=1`). Хто його відсканує, бачить вигадані картки й покупки без PIN-коду, навіть коли на ПК відкрито справжній акаунт. Гість може додавати картки й покупки — вони зберігаються окремо як демо-дані, справжні дані власника не видно й не змінюються. Виписка Monobank, синхронізація і керування ботом для гостя закриті. Вийти: кнопка «Вийти з демо» на банері.

### Telegram-бот

1. У Telegram відкрийте **@BotFather** → `/newbot` → придумайте назву й ім'я (має закінчуватися на `bot`).
2. BotFather надішле токен. Додайте його у `server/.env`: `TG_BOT_TOKEN=токен` (файл створіть із `.env.example`, якщо його ще немає). Нікому не показуйте токен і не кладіть його в ZIP.
3. Перезапустіть `start.bat`. У консолі з'явиться «🤖 Telegram-бот @… працює».
4. На сайті: **Налаштування → 🤖 Telegram-бот** — відскануйте QR-код телефоном (або надішліть боту 6-значний код). Картка зміниться на «✓ Підключено».

Що вміє бот (кнопки внизу чату):
- **💱 Курси** — НБУ, Monobank і ПриватБанк для USD та EUR;
- **💳 Мої картки** — баланс, середній курс, прибуток у гривнях і %;
- **🤔 Купувати?** — порівнює курс із вашим середнім і з курсом НБУ за 30 днів;
- **🔔 Сповіщення** — `/alert usd 41.5` (напише, коли купівля $ у Mono стане ≤ 41,5), `/alert eur > 52` (коли продаж € стане ≥ 52), `/del 2` — видалити. Сервер перевіряє курс кожні 5 хвилин;
- **🌍 Сайт** — адреса для телефона. Після `start-internet.bat` бот сам надсилає нову адресу тунелю.

Бот працює, поки запущено сервер. Код підключення одноразовий і змінюється після 5 неправильних спроб; чужим людям бот відповідає «Це приватний бот». Підключити або відв'язати бот можна лише з цього комп'ютера чи після входу за PIN.

### Які дані зберігаються

- `server/data/app.db` — ваші картки ПриватБанку й покупки (потрібні для розрахунку прибутку), а також ID вашого чату Telegram і сповіщення бота.
- `server/data/cache.json` — **лише публічні курси валют**. Виписка Monobank, ім'я, баланси і погода з координатами зберігаються тільки в пам'яті й зникають після зупинки сервера.
- Перед тим як комусь передати проєкт, видаліть папку `server/data` і файл `server/.env` — у ZIP вони не потрібні.

## Сценарій демонстрації

1. Запустіть `start.bat` і відкрийте http://localhost:8001 → розділ **«Мої картки»**. Вгорі фіолетова плашка «Демо-режим», дві картки mono (USD $1 250, EUR €680) з середнім курсом, прибутком/збитком і підказкою «Вигідно купити зараз» або «Зараз дорожче».
2. Натисніть **«+ Додати картку»**: банк «Приват», валюта USD, останні цифри `1234`, баланс `200` → «Додати». З'явиться зелена картка ПриватБанку.
3. Під цією карткою натисніть **«+ Вручну» / «+ Покупка»**: дата `2026-09-15`, сума `200`, курс `41.50` → «Зберегти». Під карткою з'явиться прибуток: вартість зараз мінус 8 300 грн.
4. **Перевірка помилкового введення:** знову «+ Покупка», сума `-100`, курс `41.50` → повідомлення «Сума у валюті має бути більшою за 0», покупка не додається. Порожня дата → «Вкажіть дату покупки». Через API дата `2026-02-30` → «Такої дати не існує».
5. На картці EUR натисніть **«💰 Купити EUR»**, введіть `100` → калькулятор покаже суму в гривнях за поточним курсом і QR-код на monobank.ua.
6. Розділ **«Курси»**: таблиця трьох джерел; на графіку оберіть EUR і 3м — зелені точки показують покупки, жовта лінія — середній курс. У конвертері введіть `100` USD → результат у гривнях.
7. Розділ **«Історія покупок»**: фільтр «USD» → «⬇ Експорт CSV» відкривається в Excel.
8. **«Налаштування»** → «Сповіщення про курс»: EUR, «вище за», `40` → «Додати» — одразу спрацює сповіщення. Увімкніть «Режим презентації» — суми й номери сховаються. «Тест фону» → «Дощ».
9. **Telegram-бот** (якщо налаштовано): тримайте телефон поруч і покажіть аудиторії (або виведіть екран телефона на проєктор).
   - «Налаштування» → «🤖 Telegram-бот» → відскануйте QR → у боті «✅ Підключено!», на сайті картка сама зміниться на «✓ Підключено».
   - У боті натисніть **«💳 Мої картки»** — ті самі баланси й прибуток, що на сайті. Потім **«🤔 Купувати?»**.
   - Надішліть `/alert usd 99` — курс уже нижчий, тож за секунду прийде «🔔 USD подешевшав!». Так виглядає сповіщення, яке прийде, коли курс справді зміниться.
   - На сайті натисніть **«📨 Надіслати тестове повідомлення»** — повідомлення з'явиться в Telegram.

## Тестування, виправлені помилки, обмеження

**Перевірено в браузері:** звичайне введення (покупка 200 USD за 41,50); порожні поля (порожня дата, сума, курс → повідомлення, запис не створюється); некоректні значення (від'ємна сума, курс 0, курс 4 150 замість 41,50 → повідомлення; сервер теж відхиляє такі дані); вузький екран 390 px (картки в стовпчик, меню знизу); темна й світла тема; недоступність одного з банків (показуються збережені курси з позначкою).

**Виправлені помилки:**
- Порожня сторінка «Курси» — розділ не показувався через помилку навігації.
- ПриватБанк не завантажувався в браузері (CORS) — запити перенесено на сервер.
- Синхронізація не знаходила покупок — читалося неіснуюче поле виписки (`operationCurrencyCode` замість `currencyCode`).
- Кнопку «Відкрити Monobank» блокував браузер — замінено на QR-код та інструкцію.
- Покупку можна було зберегти з від'ємною сумою — додано перевірку на сайті та на сервері.
- Синхронізація тривала ~6 хвилин — тепер ~1 хвилину і завантажує лише нові дані.
- У демо-режимі вручну додана покупка зберігалася, але не показувалась в історії: фільтр пропускав лише картки `demo_…`. Тепер кожен запис позначено «демо / справжній», і режими не змішуються.
- Сервер приймав неіснуючі дати (`2026-02-30`) — тепер перевіряє, що дата справжня, не в майбутньому й не раніше 2000 року.
- Виписка Monobank (описи операцій, баланси) потрапляла у `cache.json` на диск — тепер на диску лише публічні курси, старий кеш очищується при запуску.
- Після продажу валюти середній курс рахувався неправильно (продаж віднімався за ціною продажу). Тепер — метод середньої вартості: купили 100 $ по 40, продали 50 $ по 45 → середній курс лишається 40.
- Без інтернету наступного дня зникав курс НБУ — тепер показується останній збережений.
- Запити через тунель приходять на сервер з цього ж ПК, тому сервер вважав би їх «локальними» й пускав без PIN. Тепер запит із заголовками проксі (Cloudflare) завжди вважається зовнішнім.

**Обмеження:**
- Купити валюту через сайт неможливо: банки не дають такого доступу стороннім програмам.
- ПриватБанк не надає фізособам API балансу — картку Привату оновлюють вручну.
- Monobank дозволяє 1 запит виписки на хвилину, тому синхронізація не миттєва.
- Сповіщення про курс працюють, поки сайт відкритий.
- Доступ з інтернету працює, лише поки ввімкнений ПК; безкоштовна адреса Cloudflare змінюється при кожному запуску (постійна адреса потребує власного домену).
- Вдома по Wi-Fi з'єднання без HTTPS (через інтернет — з HTTPS).
